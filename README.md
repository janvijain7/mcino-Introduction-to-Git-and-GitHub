# Simple Interest Calculator

A simple Bash script that calculates simple interest from user input.

## About the Project
This project is part of the Introduction to Git and GitHub course final project.
It demonstrates forking, cloning, branching, committing, merging, and pull requests.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

- **Principal**: the initial amount of money
- **Rate**: annual interest rate (in %)
- **Time**: time period (in years)

## Usage
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example
```
Enter the principal amount: 1000
Enter the rate of interest (%): 5
Enter the time period (years): 2
Simple Interest = 100.00
```
